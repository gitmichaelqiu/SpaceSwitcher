# Automation & Dock Experience Update

## Added

- Permanent space identities via DesktopRenamer SpaceAPI v1.3.1, keeping assignments tied to the same spaces.
- Configurable rule and dock-switch HUD toasts, with concise action summaries and a detail popover.
- Dock-set reordering in settings and a dedicated Menu Bar settings section.

## Changed

- Dragging an If command now moves its matching End If with it, while commands inside the block remain independently editable and reorderable.
- Dock switching now runs asynchronously, preserves hidden and minimized window states across Dock restarts, and scopes automation to the main display.

## Fixed

- Prevented duplicate app icons in Dock recents after dock switches, including when suggested and recent apps are enabled.
- Improved rule handling for minimized windows and after Dock restarts, including restoring windows when returning to their source space.
- Rule HUD toasts now appear only when a rule produces a real window-status change.
